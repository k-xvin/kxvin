# Screw organization

I had a lot of metric screws lying around. I printed out some cases and containers to organize it.

For the case, I used this "light" variation of the Gridfinity Rugged box
* Printables: https://www.printables.com/model/873932-gridfinity-rugged-case-light-r3-150-sizes
* MakerWorld: https://makerworld.com/en/models/463249-gridfinity-rugged-case-light-r3-150-sizes
* Reddit post: https://www.reddit.com/r/gridfinity/comments/1gfqt8o/hello_rgridfinity_i_took_me_a_while_but_i_am_back

For the containers I used the Perplexing Labs generator for the shape and size I wanted. To save a minor amount of material, I set my wall thickness to 0.6mm.
* Perplexing Labs: https://gridfinity.perplexinglabs.com/pr/gridfinity-rebuilt/0/0
